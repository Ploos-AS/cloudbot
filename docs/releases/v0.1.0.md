# CloudBot container v0.1.0

Initial Ploos AS container release for CloudBot.

## Included

- CloudBot 1.4.0 pinned to upstream commit `d891d49254d5c95ddd997c0d44e03a502966ba34`
- Python 3.11 slim-bookworm runtime
- upstream source retained in-image at `/usr/src/cloudbot`
- non-root UID/GID 1000
- persistent `/data`
- safe first-run idle behavior
- `init` command for starter configuration
- `CLOUDBOT_CONFIG`
- tini PID 1
- runtime healthcheck
- Docker Compose and rootless Podman Quadlet
- multi-architecture publication for `linux/amd64` and `linux/arm64`
- GHCR semver/latest/edge tags
- BuildKit SBOM and provenance attestations
- GPL-3.0-or-later licensing and upstream attribution

## Image

`ghcr.io/ploos-as/cloudbot:0.1.0`

Release promotion occurs only after static validation, image build and smoke tests pass.
